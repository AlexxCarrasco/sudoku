1. Abrir el proyecto en IntelliJ IDEA

-   Inicia IntelliJ IDEA.
-   Selecciona File > Open.
-   Elige la carpeta del proyecto Java y ábrela.

2. Configurar la clase “Main” como punto de entrada

1.  Ve al menú superior y selecciona Run > Edit Configurations…
2.  Haz clic en + (Add New Configuration).
3.  Selecciona Application.
4.  En el campo Main class, selecciona tu clase Main de la carpeta src.
5.  En Use classpath of module, selecciona tu módulo principal.

3. Compilar el proyecto

IntelliJ compila automáticamente, pero si deseas compilar manualmente: -
Ve a Build > Build Project. - O presiona Ctrl + F9.

4. Ejecutar la clase “Main”

-   Presiona el botón Run ▶ en la esquina superior derecha.
-   O presiona Shift + F10.

5. Ver el resultado

Podras ver la gui del sudoku y probarla segun las intrucciones del informe
